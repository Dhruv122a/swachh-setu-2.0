# SwachhSetu 2.0 — Hyperlocal Citizen Grievance Dispatcher

> **Report once. Route right. Resolve faster.**
>
> ⚠️ **Prototype / Mock Municipal System** — hackathon prototype with mock data and deterministic mock AI. Not connected to any real government system.

Citizens submit **Photo + Text/Voice + Location**. Four agents then
**Understand → Prioritize → Detect Duplicates → Route → Track → Escalate → Generate Civic Insights**.

## Stack (as run in this workspace)

| Layer | Tech |
|---|---|
| Frontend | React 19 (CRA + craco), Tailwind CSS, shadcn/ui, Lucide React, Recharts, React Router |
| Backend | Python FastAPI (single `server.py`) |
| Database | One JSON file (`backend/data/complaints.json`) loaded into an **in-memory** store |
| AI | Four deterministic Python agent functions in `backend/agents/` |
| Map | Real map (Leaflet + Esri dark tiles, illustrative ward polygons); custom SVG fallback retained |
| Voice | Browser Speech Recognition (`en-IN`), with text fallback + "simulate voice" button |

> The brief suggested Vite + Node/Express. This workspace's live preview runs React + FastAPI, so the same simple architecture was kept with Python agents. Each agent is one plain function and easy to port to JavaScript.

```
backend/
  agents/triage_agent.py    triage_agent(complaint)  -> category, severity, priority, confidence, reason, factors, duplicates
  agents/routing_agent.py   routing_agent(category, ward, priority) -> department, team, P1/P2/P3, SLA, reason
  agents/action_agent.py    action_agent(complaint)  -> SLA state, escalation recommendation
  agents/insight_agent.py   insight_agent(complaints) -> trends, hotspots, charts, resource recommendation
  pipeline.py               runs the agents and builds a complaint + audit trail
  data/complaints.json      24 seeded Indore complaints (generated by data/seed_builder.py)
  server.py                 all API routes
frontend/src/
  pages/ components/ data/ services/ hooks/ App.js
```

## Setup

```bash
# backend
cd backend && pip install -r requirements.txt
uvicorn server:app --host 0.0.0.0 --port 8001
# regenerate demo data (optional)
python data/seed_builder.py

# frontend
cd frontend && yarn install && yarn start
```

Env: see `.env.example`. The frontend needs `REACT_APP_BACKEND_URL`. Data resets whenever the backend restarts (in-memory), or via `POST /api/demo/reset`.

## Pages

## API (all prefixed `/api`)

| Method | Path | Purpose |
|---|---|---|
| POST | `/complaints` | `{description, ward, location, latitude, longitude, image?, hasVoice?}` → runs all agents, returns ticket |
| GET | `/complaints` | List (filters: `q, category, ward, status, severity`), sorted by AI priority |
| GET | `/complaints/:id` | One complaint incl. `ai.triage`, `ai.routing`, `ai.duplicates`, `ai.action`, `audit` |
| POST | `/triage` | Run Triage Agent only |
| POST | `/route` | Run Routing Agent only `{category, ward, priority}` |
| POST | `/escalate` | `{ticketId, reason?}` → next level in escalation chain |
| POST | `/complaints/:id/status` | `{status, note?}` SUBMITTED, ASSIGNED, INSPECTION_SCHEDULED, IN_PROGRESS, RESOLVED |
| POST | `/complaints/:id/override` | `{accept:true}` or `{category?, priority?, department?, team?, note?}`. The AI result is preserved |
| POST | `/complaints/:id/feedback` | `{resolved: bool}`. If false, the Action Agent recommends escalation |
| POST | `/complaints/:id/simulate-breach` | Demo helper |
| GET | `/dashboard` | KPI demo metrics + AI priority queue |
| GET | `/hotspots` | Insight Agent output |
| GET | `/duplicates` | Duplicate clusters, or `?ticketId=` for one |
| GET | `/meta` | Wards, categories, departments, teams |
| POST | `/demo/reset` | Reload seed data |

## How the priority score works (deterministic)

| Factor | Rule |
|---|---|
| Public health risk | by category (garbage/sewage 30 … streetlight 14) |
| Severity | category base + 7 if words like *overflow, burst, accident, deep* |
| Duration | ≥3 days / week → 20, 1–2 days / yesterday → 12, else 6 |
| Location density | ward density + 2 for public places (park, school, market…), max 10 |
| Nearby complaints | 3 × open same-category complaints within 300 m, max 9 |

Demo: *"Garbage has been overflowing for three days near the community park."* at Shivaji Nagar → 30+25+20+10+9 = **94**, HIGH, P1, 4-hour SLA, Solid Waste Management → Ward 17 Sanitation Team, 3 duplicates (92 % similarity, 33 m).

## Trust & safety
Every AI output shows **Recommendation, Confidence, Reason and Timestamp**. Officer overrides are stored separately in `officerDecision` and the audit trail. AI results are never overwritten silently. Citizens appear only as an anonymous hash (`Citizen #A1B2C`).
